# Decision records

`log.md` holds smaller decisions as one-line Y-statements, newest last.
Numbered full records (`NNNN-kebab-title.md`) are reserved for decisions that
are hard to reverse or deliberately absent, and creating one needs Oliver's
explicit confirmation; a log entry needs no permission and can be promoted
later.

## The gate

Every entry names the alternative that lost — one someone with the same
information and intent could have chosen — and the cost it accepts. A decision
that names neither is not a decision: write nothing.

## Immutability

Entries are written and left alone. A change of position is a later entry or a
superseding record that names its predecessor; only a record that says
something untrue is corrected in place.
